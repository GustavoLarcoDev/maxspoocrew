How they are built, and how to change one

Each scene is one HTML file: SVG artwork and CSS keyframes, no library and nothing generated. The type on the end card is real text over the scene, never drawn into it — the same rule the two commercials in /ads/ follow, and for the same reason: a number drawn into a picture cannot be corrected without redrawing the picture.

All five share scenes/_scene.css, which holds the artwork styling and one 11-second timeline. Because every element runs on that one clock, the beats stay in step with each other:

  • Change the number, the website or the tagline → edit the six lines at the foot of each scene file.
  • Change the timing or the artwork for all five → edit _scene.css.
  • Change a scene’s light or its dog → edit the handful of custom properties at the top of that scene.

Then python build_video.py re-renders the MP4s. It drives each scene through ?t= — open scenes/scene-1-morning.html?t=6.3 to freeze the loop at 6.3 seconds — so a frame is reproducible rather than a recording of whatever the browser managed at the time.
